### Cracklepop

This program will print a number 1 to 100, multiples of 3 will print Crackle, 
multiples of 5 will print Pop, multiples of both will print CracklePop. 

To run, make sure you have go installed then run `go run main.go` from 
the root directory. To change the max number to print up to, specify 
a valid positive value for the environment variable `MAX_NUM`. 
Ex: `MAX_NUM=5 go run main.go`
